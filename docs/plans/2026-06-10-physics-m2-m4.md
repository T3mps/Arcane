## Key design decisions

- **GJK without EPA** (standing decision): GJK runs on shape CORES — point
  (circle), segment (capsule), polygon (aabb/poly) — and radii are subtracted
  from the core distance afterward. Exact distance + closest points for our
  whole shape set; penetration recovery stays SAT/specials (M1) and CCD
  *prevents* deep overlap rather than resolving it.
- **shapeCast = conservative advancement on GJK distance** (translation-only:
  `t += dist/|d|`, capped iterations, tolerance ~0.05px).
- **Exact raycast = point shapeCast** for circle/capsule/poly bodies; AABB keeps
  the (already exact) slab test. Cells keep DDA, gaining a TALL-only LOS filter
  (`obstacleClass == TALL` blocks sight; LOW blocks movement only).
- **CCD**: per-body `bullet` flag; flagged movers clamp integration to TOI vs
  statics inside `step()`.
- **M3 adds rotational state** (angle/angVel/invInertia in the SoA): Revolute/
  Prismatic/Weld are meaningless without it. Circle is rotation-invariant;
  capsule/polygon transform through scratch buffers; the AABB shape stays
  axis-aligned and is therefore restricted to fixedRotation bodies (asserted).
- **Manifolds for the solver**: 1–2 contact points per pair (reference-face
  clipping for poly/poly + poly/capsule-face; analytic single point for round
  pairs), stored on ContactManager pairs with accumulated normal/tangent
  impulses (warm start).
- **Islands**: union-find over awake dynamic bodies via contact+joint edges;
  an island sleeps when every body has been below the velocity thresholds for
  0.5s; any contact/joint/teleport from an awake body wakes the island.
- **M4 broadphases**: `SAP` + `AABBTree` behind the same insert/remove/update/
  queryAABB/pairs surface as SpatialHash; world option `broadphase = "hash" |
  "sap" | "tree"`; harness runs identical scenes across all three and asserts
  identical (narrowed) pair sets.
- **Determinism replay (M4)**: scripted input sequence over a mixed scene →
  FNV-1a hash of all body states each step; two runs must produce identical
  hashes. Contact processing is made order-stable (sort pair list) to extend
  determinism to events.
